Open Lo-Fi keeps — FM1 v2 (warmer, distinctive)

A/B against v1 and the originals. Same notes, progressions, drums, fills and BPM as v1 — only two things changed: the lead is an octave lower, and each track now gets its own real SLOOP instrument pack instead of sharing one host sound. 8 bars each, gain-matched to −23.0 dBFS RMS, so loudness is comparable across v1/v2.

Why v1 sounded tinny and samey: 6 of 7 v1 tracks shared one host sound (Amen group A: vibes lead, atmos pad, jungle kit), and both v1 lead sounds are metallic/bell-like, played an octave up and stacked with pads. That is the same bright-lead mechanism as the earlier Orbit "ouch". V2 fixes it with instruments already in the FM1 firmware — no new samples, no invented presets.

What changed, exactly (and what did not)

  • Lead −12 semitones on every note (dump-checked: bass, chords, drums, slots, fills byte-identical to v1).
  • Instruments: each track's bass/lead/chord engines + presets + drum kit taken verbatim from SLOOP's existing level profiles (see per-track notes above). No new data, no invented presets.
  • Nothing else: same progressions (still proposals, not transcriptions), same host keys (A minor / A major), same BPM, same fills, same 8 bars.
  • Verification: all 7 WAVs deterministic across two renders, snapshot PASS, dump checks PASS, MP3s gain-matched −23.0 dBFS. Brightness drop measured (6–12 kHz energy share), not just claimed.
  • These are still listening renders, not production levels. The per-track instrument choices here are a demonstration in the renderer — they are NOT yet assigned to any production level or kit. Nothing merged, no pointer moved, no flash, no composition-core change.
