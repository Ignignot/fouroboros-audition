Sub-bass variants — 2am, cafe, candlelit

Task: bounded V1 sub-bass REVIEW (not BLOCK, not a redesign, no global boost). Variants are listening candidates only — no production change, no merge, no pointer move. Controls are the v2 originals (byte-identical MP3s from the v2 page). All clips gain-matched to −23.0 dBFS RMS, so A/B loudness is fair; shares below are gain-invariant (Welch spectra, WAV vs WAV, same chain). Kick steps are identical in patterns for all three (drums untouched; 2am/cafe patterns byte-identical, only the bass preset differs; candlelit differs only in chord velocity). Kick voice itself is unchanged (same kit, steps, levels); shared FX tails may shift slightly with the mix — kick clarity in the mix is for your ears. Listen, then decide in chat — no tap here counts as a decision.

1. Cafe — bass preset swap (weak sub → upright sustain)

Change (one): bass PHYS PLUCK BASS → SAMPLE UP BASS (upright), same notes, same rhythm. Pluck bass decays fast (weak sustained sub); upright rings longer. Bossa-authentic (upright is the bossa bass), not a synth sub.

Measured: sub (30–80 Hz) 7.0% → 31.9% (healthy range, cf. Boom Bap 33–37%); masking ratio (150–300 / sub) 3.23 → 0.33; 150–300 share 22.7% → 10.6%. Per-hit attacks similar (both plucked); the gain is sustain — sub present between hits.

2. 2am — bass preset swap (weak sub → analog sub)

Change (one): bass DIGITAL FM BASS → ANALOG SUB BASS, same notes, same rhythm. FM bass fundamental is weak per hit; analog sub is sine-like (strong fundamental, few harmonics, so it adds sub without adding low-mid crowding — 2am chords already dominate 150–300 Hz).

Measured: sub 6.9% → 7.9% (modest); masking ratio 6.46 → 5.39; per-hit 55 Hz fundamental +0.2 to +1.2 dB (small, consistent). Honest limit: 2am bass plays only 3 notes/bar, gate-limited, so time-averaged share stays low regardless of timbre — sparsity caps share. If this variant is not enough, the next lever would be density, sustain, or level (bigger changes, not in this packet).

3. Candlelit — chord dynamics down (masked sub → unmask, not boost)

Change (one): every chord note SOFT (velocity 72) → GHOST (velocity 42). No note, register, rhythm, or timbre change; bass, lead, and drums untouched. Chords softer (dynamics), sub relatively clearer — unmasking, not a sub boost.

Measured: sub 20.4% → 22.7% (modest); masking ratio 2.11 → 1.92; bass 55 Hz fundamental +3.1 dB at the loudest step (bass+chord+lead together — likely less bus clipping with softer chords; inference, not proven). Honest limit: candlelit chords play only 2 steps/bar and the lead dominates 150–300 Hz (lead unchanged), so softening chords moves shares only a little. Candlelit sub was already decent (20%); this is a gentle unmasking.
